# CALICO Fall '26 Contestant Submissions

This repository contains all contestant submissions from CALICO Fall '26.

## Structure

```
submissions/
  <team_id> - <team_name>/
    <problem_name>/
      <submission_id>-<username>-<problem_name>-<submission_time>-<verdict>.<ext>
```

- **Team directories** — Each top-level directory is named `<team_id> - <team_name>` (609 teams total).
- **Problem directories** — Within each team, subdirectories are named by problem (e.g. `laser_main`, `grid_bonus`).
- **Source files** — Individual submissions named using submission ID, contestant username, problem name, contest time (minutes from start), and judge verdict.
